# AkiSuite icon family

AkiHQ.app is served from this repository's `release/akihq-management-brand-v1` branch. The AkiHQ mark is a black (`#111111`) AkiPasa-proportion pin, gold (`#FFC533`) four-point star and white (`#FFFFFF`) 128 × 128 square with 29px corner radius. Regular PNGs and safe-zone maskable PNGs are generated by `scripts/generate-brand-icons.mjs` on every dev and build. **Do not confuse this repo with the separate `akihq` repository's `release/akibusiness-operations-brand-v1` branch, which owns the purple AkiBusiness AB monogram. Do not overwrite the AB icon.**

The AkiHQ web build generates versioned, untracked `hq-v2-*.png` assets so the release-source dirty-tree guard stays green and already-installed PWAs can refresh. No tracked/legacy PNGs are overwritten during the build.
