# Customer inbox readiness

The ordinary-business inbox is a workspace conversation record, not a working email/WhatsApp delivery adapter. It now states that clearly before use, saves explicitly labelled internal notes, and does not generate fictitious customer conversations when records are missing. The platform mailbox keeps its existing provider-backed send path and access controls.

External provider onboarding, callback approval and mailbox delivery remain a release gate for offering these integrations to paying customers. Do not enable platform integration endpoints for other tenants as a shortcut. The Worker deployment still requires Cloudflare access and independent verification.

Physical receipt printing stays paused at Alex's earlier request. Fiscal submission, real payment acquiring and hardware acceptance are not certified by this UI release.
