# Changelog

## 0.1.0 — 2026-08-04

Initial working alpha release.

- Added responsive local-first workspace shell and original visual system.
- Added dashboard, CRM, inbox, tasks/projects, calendar, inventory, sales, marketing, sites/forms, automation, collaboration, employees, knowledge, analytics, integrations and settings modules.
- Added CRM Kanban drag-and-drop, entity CRUD, lead conversion and activity timeline.
- Added JSON backup/restore, CSV export and Bitrix24 CSV import.
- Added command palette, global search, notifications, timer, themes, density and language settings.
- Added optional Supabase snapshot sync schema.
- Added optional Cloudflare Worker integration gateway.
- Added PWA manifest, offline shell, Pages headers and deployment documentation.
